# Accessibility Design Review

- [ ] User task, recovery path, and relevant input methods are known.
- [ ] Information is not conveyed by color or motion alone.
- [ ] Mobile layout survives 405 × 720 and realistic text expansion.
- [ ] Primary touch targets follow Elara's approximately 44 × 44 CSS pixel goal where applicable.
- [ ] Focus will remain visible and unobscured by fixed or modal UI.
- [ ] Dialog/sheet initial focus, close behavior, and focus return are intentional.
- [ ] Forms have visible labels, recoverable errors, preserved values, and perceivable success.
- [ ] Drag, swipe, or other gestures have practical alternatives where required.
- [ ] Reduced-motion behavior is defined for meaningful animation.
- [ ] Custom widgets have a documented reason over native or maintained alternatives.
- [ ] Consequential approval/action states remain distinguishable without visual inference.
