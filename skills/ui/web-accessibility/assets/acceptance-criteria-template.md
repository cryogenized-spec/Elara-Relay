## Criteria

- [ ] Native semantics communicate the intended structure and control purpose.
- [ ] Important controls expose correct role, name, state, and value.
- [ ] Keyboard-only operation can start, complete, cancel, and recover from the task.
- [ ] Focus remains visible and unobscured.
- [ ] Primary mobile controls meet Elara's approximately 44 × 44 CSS pixel target where applicable.
- [ ] Required pointer gestures have a non-drag / keyboard alternative where applicable.
- [ ] Errors are specific, associated, discoverable, and recoverable without unnecessary data loss.
- [ ] Status and meaning do not depend on color alone.
- [ ] Dynamic changes are perceivable without unnecessary focus theft.
- [ ] Relevant zoom, reflow, long text, reduced motion, and mobile states are covered.
- [ ] Composite widgets have a documented keyboard/focus contract when present.
